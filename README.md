# 🌦️ Weather Application
 
A Salesforce Lightning Web Components (LWC) application that provides real-time weather information through a third-party weather API. The application displays weather details such as temperature, humidity, weather conditions, and corresponding icons through a responsive and interactive user interface.
 
## Features
 
- Real-time weather data retrieval
- Search weather by city
- Display temperature, humidity, and weather conditions
- Dynamic weather icons
- Responsive user interface
- External API integration
- Apex server-side processing
- Experience Cloud deployment
 
## Technologies Used
 
- Salesforce Platform
- Lightning Web Components (LWC)
- Apex
- HTML
- CSS
- JavaScript
- Salesforce Lightning Design System (SLDS)
- Experience Cloud
- Third-Party Weather API
 
## Project Architecture
 
### Client Side (LWC)
- Handles user input and UI rendering
- Displays weather details dynamically
- Uses data binding and event handling
 
### Server Side (Apex)
- Performs secure API callouts
- Processes API responses
- Returns weather data to LWC components
 
### Static Resources
- Stores weather icons and visual assets
 
## Key Functionalities
 
### Weather Search
Users can search for weather information based on city name.
 
### Current Weather Details
The application displays:
- Temperature
- Humidity
- Weather Condition
- Weather Icon
 
### Responsive Design
Built using SLDS and custom CSS for an enhanced user experience across devices.
